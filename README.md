<h3>Purpose of This Project</h3>
The purpose of this project is to aesthetically and interactively display the coffee and dessert selections for the "Camper Cafe."<br>
The coffee and dessert items should be selectable. You can select more than one item and the total price will display at the bottom of the menu. As you unselect an item, the price of that item will be subtracted from the total price displayed at the bottom.<br>

<h3>Important Information</h3>
<h4>The JavaScript in this project should allow you to:</h4>
<ul>
  <li>See the mouse cursor turn into a pointer (hand) when hovering over a menu item</li>
  <li>Click / tap on one or multiple items to select them</li>
  <li>See the total price of one or more selected items at the bottom of the menu</li>
  <li>Deselect an item you selected by clicking / tapping it again</li>
  <li>See the price of deselected items subtract from the total price at the bottom of the menu</li>
</ul>
This is a project from freecodecmp.org.<br>
Although originally a simple HTML project, I added CSS styling and JavaScript interactivity.
